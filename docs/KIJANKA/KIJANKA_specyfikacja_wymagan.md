# KIJANKA — specyfikacja wymagań prototypu

## 1. Wymagania funkcjonalne
- przejazd po planie w osi przód–tył
- powtarzalny zapis i odtwarzanie ruchu
- aktywna kompensacja nierówności
- integracja z TARZAN / EHR / TAKE

## 2. Wymagania mechaniczne
- sztywna baza dolna
- 4 moduły kompensacyjne kół
- serwo z hamulcem przy każdym kole
- śruba kulowa jako mechanizm liniowy
- możliwość serwisowego demontażu

## 3. Wymagania sterownicze
- odczyt IMU / XYZ
- kontrola lokalna napędów
- logika bezpieczeństwa
- integracja z systemem nadrzędnym

## 4. Wymagania bezpieczeństwa
- hamulec po zaniku zasilania
- E-STOP
- ograniczniki mechaniczne
- krańcówki / referencje
- tryb bezpiecznego zatrzymania

## 5. Wymagania produkcyjne
- możliwie szybka budowa prototypu
- ograniczenie liczby elementów specjalnych
- wycinanie z dostępnego materiału
- etapowanie: 1 koło -> 4 koła -> integracja

## 6. Wymagania projektowe
- priorytet: czas wejścia do gotowego ujęcia
- nie budować dla formalizmu
- budować dla działania i powtarzalności
